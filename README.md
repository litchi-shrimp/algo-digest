## 这是什么仓库

这里是**我个人学习算法的笔记存档**。

不是论文翻译，不是教程搬运。每篇笔记都是我读完论文/代码后，用自己的话重新组织、加入个人理解的产物。

**写作原则**：

- ❌ 不堆砌公式 — 公式是辅助理解的，不是主角
- ❌ 不照搬论文 — 论文结构 ≠ 最适合学习的结构
- ✅ 从"为什么"开始 — 先讲动机，再讲方法
- ✅ 举例驱动 — 能用例子讲清楚就不用抽象描述
- ✅ 反问思考 — 好的问题是理解的一半
